# Memory Game: Two by two
Ajută-l pe Noe să salveze animalele înainte ca potopul să înceapă! Găsește perechile de animale și testează-ți cunoștințele despre ele într-o cursă contra cronometru. Cu fiecare pereche găsită, răspunde corect la întrebări pentru a le păstra în siguranță pe arcă. Dar ai grijă - un răspuns greșit va reseta toate cărțile!

## Resurse

- [SFML](https://github.com/SFML/SFML/tree/2.6.1) (Zlib)
  - [OpenAL](https://openal-soft.org/) (LGPL): din cauza licenței, trebuie distribuită ca shared library
- Grafica cărților de joc: Dezvoltată special pentru acest proiect, utilizând platforma [Canva](https://www.canva.com/) pentru un design personalizat (creații originale).
- Imagine de fundal principală: Preluat de pe această [sursă](https://bushcraftbuddy.com/the-survival-aspects-of-noahs-ark/), extinsă și prelucrată utilizând Adobe Photoshop.
- Fundaluri pentru întrebări și mesaje (start/failure/success): Create și personalizate cu ajutorul platformei [Canva](https://www.canva.com/) (creații originale).
- Melodia principală: [Heaven is free](https://www.youtube.com/watch?v=jG45gKJfe4M) de Kevin MacLeod.
- Efect sonor timer final: Disponibil [aici](https://www.youtube.com/watch?v=xtQcMx5WItE).
